기록장 — 주간 금리 레인지 L0 + L1

L0(기계 밴드)는 자동 적립 · L1(재량 조정)은 여기서 입력 · 채점은 목표일 종가 도착 시 자동 — 전망 vs 실제의 누적 대조와 원인 노트로 전망 정확도를 키우는 페이지
잠금 해제 — 비밀번호를 입력하세요.
최초 설정: GitHub fine-grained 토큰(대상 저장소 research-data 만, 권한 Contents: Read and write)을 붙여넣고 비밀번호(12자 이상)를 정하세요. 토큰은 이 브라우저의 localStorage 에 AES-GCM 으로 암호화되어 저장되며 GitHub API 호출 외 어디로도 전송되지 않습니다.
여러 PC/브라우저를 쓰신다면 기기마다 1회씩 위 설정을 하세요. 봉인은 이 브라우저 안에만 있고 어디로도 발행되지 않습니다 — 암호문이 공개 포털에 올라가는 경로는 이 페이지에 존재하지 않습니다.
토큰 만드는 법
github.com → Settings → Developer settings → Fine-grained tokens → Generate new token → Repository access: Only select repositories → research-data → Permissions → Repository permissions → Contents: Read and write → Generate. 만료는 90일~1년 권장(만료 시 재설정으로 교체).
